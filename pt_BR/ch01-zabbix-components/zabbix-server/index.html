    Iniciante

    Instalando o servidor Zabbix

    Agora que adicionamos o repositório Zabbix com os softwares necessários, estamos prontos para instalar tanto o servidor Zabbix quanto o servidor web. Lembre-se de que o servidor web não precisa ser instalado na mesma máquina do servidor Zabbix; eles podem ser hospedados em sistemas separados se desejado.

    Para instalar os componentes do servidor Zabbix, execute o seguinte comando:

    Instale o zabbix server

    Red Hat 

    # For MySQL/MariaDB backend:
dnf install zabbix-server-mysql
# For PostgreSQL backend:
dnf install zabbix-server-pgsql

    SUSE 

    # For MySQL/MariaDB backend:
zypper install zabbix-server-mysql
# For PostgreSQL backend:
zypper install zabbix-server-pgsql

    Ubuntu 

    # For MySQL/MariaDB backend:
sudo apt install zabbix-server-mysql
# For PostgreSQL backend:
sudo apt install zabbix-server-pgsql

    Após a instalação bem-sucedida do pacote do servidor Zabbix, precisamos configurar o servidor Zabbix para se conectar ao banco de dados. Isso requer a modificação do arquivo de configuração do servidor Zabbix.

    O arquivo de configuração do servidor Zabbix oferece uma opção para incluir arquivos adicionais de configuração para parâmetros personalizados. Em um ambiente de produção, é geralmente melhor evitar alterar diretamente o arquivo de configuração original. Em vez disso, você pode criar e incluir arquivos de configuração separados para quaisquer parâmetros adicionais ou modificados. Essa abordagem garante que seu arquivo de configuração original permaneça inalterado, o que é particularmente útil ao realizar atualizações ou gerenciar configurações com ferramentas como Ansible, Puppet ou SaltStack.

    Em SUSE 16 e versões posteriores, essa funcionalidade já está habilitada e configurada por padrão. (veja também https://documentation.suse.com/sles/16.0/html/SLE-differences-faq/index.html#sle16-differences-faq-basesystem-etc). Portanto, nos sistemas SUSE, o arquivo de configuração do servidor Zabbix é localizado em /usr/etc/zabbix/zabbix_server.conf, e está configurado para incluir todos os arquivos .conf no diretório /etc/zabbix_server/zabbix_server.d/.

    Em outras distribuições, você pode precisar habilitá-la manualmente:

    Para habilitar essa funcionalidade, certifique-se de que a próxima linha existe e não está comentada (com um # na frente dela) em /etc/zabbix/zabbix_server.conf:

    # Include=/usr/local/etc/zabbix_server.conf.d/*.conf
Include=/etc/zabbix/zabbix_server.d/*.conf

    O caminho /etc/zabbix/zabbix_server.d/ já deve ter sido criado pelo pacote instalado, mas certifique-se de que realmente existe.

    Agora criaremos um arquivo de configuração personalizado database.conf no diretório /etc/zabbix/zabbix_server.d/ que conterá nossas configurações de conexão com o banco de dados:

    Adicione as configurações de conexão do banco de dados Zabbix

    vi /etc/zabbix/zabbix_server.d/database.conf

    Adicione as seguintes linhas no arquivo de configuração para corresponder à sua configuração de banco de dados:

    # Zabbix database configuration
DBHost=<database-host>
DBName=<database-name>
DBSchema=<database-schema>  # Only for PostgreSQL
DBUser=<database-user>
DBPassword=<database-password>
DBPort=<database-port>

    Substitua <database-host>, <database-name>, <database-schema>, <database-user>, <database-password> e <database-port> pelos valores apropriados para sua configuração. Isso garante que o servidor Zabbix possa se comunicar com seu banco de dados.

    Certifique-se de que não há # (símbolo de comentário) na frente dos parâmetros de configuração, pois o Zabbix tratará linhas iniciadas com # como comentários, ignorando-as durante a execução. Além disso, verifique novamente por linhas de configuração duplicadas; se houver várias linhas com o mesmo parâmetro, o Zabbix usará o valor da última ocorrência.

    Para nossa configuração, a configuração será assim:

    Exemplo database.conf

    MariaDB/MySQL: 

    # MariaDB database configuration
DBHost=<ip or dns of your MariaDB server>
DBName=zabbix
DBUser=zabbix-srv
DBPassword=<your super secret password>
DBPort=3306

    PostgreSQL: 

    # PostgreSQL database configuration
DBHost=<ip or dns of your PostgreSQL server>
DBName=zabbix
DBSchema=zabbix_server
DBUser=zabbix-srv
DBPassword=<your super secret password>
DBPort=5432

    Para PostgreSQL em HA

    Com o Zabbix 8.0 é agora possível adicionar mais de 1 IP para DBHost. Dessa forma é possível configurar um ambiente HA com PostgreSQL sem a necessidade de usar um balanceador de carga. O Zabbix detectará o banco ativo por conta própria. Ex: DBHost=192.168.10.2:5432,192.168.10.3:5432

    Neste exemplo:

    • DBHost se refere ao host onde seu banco de dados está rodando (use localhost se estiver na mesma máquina).
    • DBName é o nome do banco de dados Zabbix.
    • DBSchema é o nome do esquema usado no PostgreSQL (somente necessário para PostgreSQL).
    • DBUser é o usuário do banco de dados.
    • DBPassword é a senha para o usuário do banco de dados.
    • DBPort é o número da porta em que seu servidor de banco de dados está escutando (padrão para MySQL/MariaDB é 3306 e PostgreSQL é 5432).

    Certifique-se de que as configurações refletem a configuração do banco de dados do seu ambiente.

    Configure o firewall para permitir conexões Zabbix trapper

    Voltando à sua máquina servidor Zabbix, precisamos garantir que o firewall esteja configurado para permitir conexões entrantes ao servidor Zabbix.

    Seu servidor Zabbix precisa aceitar conexões entrantes de agentes, enviadores e proxies do Zabbix. Por padrão, o Zabbix usa a porta 10051/tcp para essas conexões. Para permitir essas conexões, você precisa abrir essa porta no seu firewall.

    Abra o firewall para zabbix-trapper

    Red Hat / SUSE 

    sudo firewall-cmd --add-service=zabbix-trapper --permanent
sudo firewall-cmd --reload

    Ubuntu 

    sudo ufw allow 10051/tcp

    Se o serviço não for reconhecido usando firewall-cmd --add-service, você pode especificar manualmente a porta:

    Adicione a porta em vez do nome do serviço

    firewall-cmd --add-port=10051/tcp --permanent

    Iniciando o servidor Zabbix

    Com a configuração atualizada do servidor Zabbix para se conectar ao seu banco de dados, você pode agora iniciar e habilitar o serviço do servidor Zabbix. Execute o seguinte comando para habilitar o serviço do servidor Zabbix e garantir que ele seja iniciado automaticamente no boot:

    Note

    Antes de reiniciar o servidor Zabbix após modificar sua configuração, é considerada uma boa prática validar a configuração para prevenir possíveis problemas. Executar um teste de configuração garante que quaisquer erros sejam detectados antes, evitando downtime causado por uma configuração inválida. Isso pode ser feito usando o seguinte comando: zabbix-server -T

    Habilitar e iniciar serviço zabbix-server

    Red Hat, SUSE e Ubuntu 

    sudo systemctl enable zabbix-server --now

    Este comando iniciará imediatamente o serviço do servidor Zabbix e configurará para que ele seja lançado no início da inicialização do sistema. Para verificar se o servidor Zabbix está funcionando corretamente, verifique o arquivo de log para mensagens. Você pode visualizar as entradas mais recentes no arquivo Zabbix server usando:

    Verificar o arquivo de log

    tail /var/log/zabbix/zabbix_server.log

    Conclusão

    Com a instalação e configuração bem-sucedidas do servidor Zabbix, você agora estabeleceu o componente principal de seu sistema de monitoramento. Cobrimos a instalação do pacote do servidor Zabbix, a configuração das configurações de conexão com o banco de dados e a configuração do firewall para permitir conexões entrantes ao servidor Zabbix. Além disso, iniciamos o serviço do servidor Zabbix e verificamos sua operação.

    Seu servidor Zabbix está agora pronto para se comunicar com os agentes, enviadores e proxies Zabbix. A próxima etapa é instalar e configurar a interface frontal do Zabbix, que fornecerá a interface de usuário para interagir com seu sistema de monitoramento.

    Vamos prosseguir para o próximo capítulo para configurar a interface frontal do Zabbix.
