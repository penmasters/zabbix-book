    Ein MariaDB-Datenbanksystem installieren

    In diesem Abschnitt werden wir die Pakete für den MariaDB-Server und -Client installieren. Dies stellt die notwendigen Komponenten bereit, um MariaDB als Datenbankbackend für Zabbix zu betreiben.

    Wenn Sie PostgreSQL als Datenbankbackend bevorzugen, können Sie diesen Abschnitt überspringen und mit dem PostgreSQL-Datenbanksystem installieren Abschnitt fortfahren.

    MySQL/Percona

    Wenn Sie MySQL oder Percona anstelle von MariaDB bevorzugen, sind die Installations- und Konfigurationsanweisungen sehr ähnlich. Allgemein ersetzen Sie mariadb durch mysql in den Paketnamen und Befehlen.

    MariaDB Server und Client aus Betriebssystem-Paketen installieren

    Um das vom Betriebssystem bereitgestellte Standard-MariaDB-Datenbanksystem zu installieren, führen Sie den folgenden Befehl aus:

    Installiere die von der Distribution bereitgestellte Version von Mariadb

    Red Hat 

    dnf install mariadb-server

    SUSE 

    zypper install mariadb mariadb-client

    Ubuntu 

    sudo apt install mariadb-server

    Dieser Befehl lädt und installiert sowohl den Server- als auch den Client-Paket, sodass Sie das MariaDB-Datenbanksystem einrichten, konfigurieren und nutzen können. Sobald die Installation abgeschlossen ist, können Sie mit dem Starten des MariaDB-Datenbanksystems Abschnitt fortfahren.

    MariaDB Server und Client aus den offiziellen MariaDB-Repositorien installieren

    Wenn Sie die Installation von MariaDB aus den offiziellen MariaDB-Repositorien bevorzugen, müssen Sie zunächst das MariaDB-Repositorium zu Ihrem System hinzufügen.

    Das MariaDB-Repositorium hinzufügen

    Um die Datei für das MariaDB-Repositorium zu erstellen, führen Sie im Terminal folgenden Befehl aus:

    Definiere das MariaDB-Repositorium

    Red Hat 

    vi /etc/yum.repos.d/mariadb.repo

    SUSE 

    sudo vi /etc/zypp/repos.d/mariadb.repo

    Ubuntu 

    sudo apt install apt-transport-https curl
sudo mkdir -p /etc/apt/keyrings
sudo curl -o /etc/apt/keyrings/mariadb-keyring.pgp 'https://mariadb.org/mariadb_release_signing_key.pgp'

sudo vi /etc/apt/sources.list.d/mariadb.sources

    Dies öffnet einen Texteditor, in dem Sie die Konfigurationsdetails für das Repository eingeben können. Sobald das Repository konfiguriert ist, können Sie mit der Installation von MariaDB fortsetzen, indem Sie Ihren Paket-Manager verwenden.

    Die neueste Konfiguration kann hier gefunden werden: https://mariadb.org/download/?t=repo-config

    Nachdem Sie die Datei gespeichert haben, stellen Sie sicher, dass alles korrekt eingerichtet ist und dass Ihre bevorzugte MariaDB-Version mit Ihrer Zabbix-Version kompatibel ist, um potenzielle Integrationsprobleme zu vermeiden.

    MariaDB Server und Client installieren

    Mit dem konfigurierten MariaDB-Repositorium sind Sie nun bereit, die Pakete für den MariaDB-Server und -Client zu installieren. Dies stellt die notwendigen Komponenten zur Verfügung, um das Datenbanksystem zu betreiben und zu verwalten.

    Um den MariaDB-Server und -Client zu installieren, führen Sie folgenden Befehl aus:

    Installiere MariaDB aus dem offiziellen Repository

    Red Hat 

    dnf install MariaDB-server

    SUSE 

    sudo rpm --import https://mirror.bouwhuis.network/mariadb/yum/RPM-GPG-KEY-MariaDB
sudo zypper install MariaDB-server MariaDB-client

    Ubuntu 

    sudo apt install mariadb-server

    Dieser Befehl lädt und installiert sowohl den Server- als auch den Client-Paket, sodass Sie das MariaDB-Datenbanksystem einrichten, konfigurieren und nutzen können. Sobald die Installation abgeschlossen ist, können Sie mit dem Starten des MariaDB-Datenbanksystems Abschnitt fortfahren.

    Starten des MariaDB-Datenbanksystems

    Nun, da MariaDB installiert ist, müssen wir den Dienst so einrichten, dass er beim Systemstart automatisch gestartet wird und sofort gestartet werden kann. Verwenden Sie folgenden Befehl, um dies zu erreichen:

    Aktiviere MariaDB-Dienst

    sudo systemctl enable mariadb --now

    Dieser Befehl aktiviert den MariaDB-Dienst und startet ihn sofort. Da es sich hierbei um die erste Startung handelt, wird das Datenbankverzeichnis initialisiert. Mit dem laufenden MariaDB-Dienst können Sie nun überprüfen, ob die Installation erfolgreich war, indem Sie die Version von MariaDB mit folgendem Befehl prüfen:

    Überprüfe Mariadb-Version

    mariadb -V

    Die erwartete Ausgabe sollte wie folgt aussehen:

    Beispiel für MariaDB-Version 
    localhost:~ $ mariadb -V
mariadb from 11.4.13-MariaDB, client 15.2 for Linux (aarch64) using  EditLine wrapper

    Um sicherzustellen, dass der MariaDB-Dienst ordnungsgemäß läuft, können Sie mit dem folgenden Befehl den Status prüfen:

    Überprüfe mariadb-Status

    sudo systemctl status mariadb

    Sie sollten eine Ausgabe ähnlich wie diese sehen, was bedeutet, dass der MariaDB-Dienst aktiv und läuft:

    Sicherung des MariaDB-Datenbanksystems

    Um die Sicherheit Ihres MariaDB-Servers zu erhöhen, sollten Sie unnötige Testdatenbanken entfernen, anonyme Benutzer löschen und ein Passwort für den Root-Benutzer festlegen. Dies kann mit dem Skript mariadb-secure-installation durchgeführt werden, das eine Schritt-für-Schritt-Anleitung zur Sicherung Ihrer Datenbank bietet.

    Führen Sie folgenden Befehl aus:

    Sichere MariaDB-Einrichtung

    sudo mariadb-secure-installation

    Das Skript mariadb-secure-installation führt Sie durch mehrere wichtige Schritte:

    1. Setzen eines Root-Passworts, falls noch keines gesetzt ist.
    2. Entfernen anonymer Benutzer.
    3. Verhindern von Fernwartungen für den Root-Benutzer.
    4. Entfernen der Testdatenbank.
    5. Aktualisieren der Berechtigungslisten, um die Änderungen wirksam zu machen.

    Nach Abschluss ist Ihr MariaDB-System erheblich sicherer.

    Sie sind nun bereit, die Datenbank für Zabbix einzurichten.

    Erstellen der Zabbix-Datenbankinstanz

    Mit MariaDB jetzt eingerichtet und gesichert können wir fortfahren mit dem Erstellen der Datenbank für Zabbix. Diese Datenbank speichert alle notwendigen Informationen zum Zabbix-Server, einschließlich Konfigurationsdaten und Überwachungsdaten.

    Führen Sie die folgenden Schritte aus, um die Zabbix-Datenbank zu erstellen:

    Melden Sie sich als root-Benutzer im MariaDB-Skript an: Sie werden aufgefordert, das Passwort für den root-Benutzer einzugeben, das Sie während des Prozesses mariadb-secure-installation gesetzt haben.

    Loggen Sie sich in Mariadb als Benutzer root ein

    mariadb -uroot -p

    Sobald Sie im MariaDB-Skript angemeldet sind, führen Sie den folgenden Befehl aus, um eine Datenbank für Zabbix zu erstellen:

    Erstellen der Datenbank

    MariaDB [(none)]> CREATE DATABASE zabbix CHARACTER SET utf8mb4 COLLATE utf8mb4_bin;
    Was ist utf8mb4

    utf8mb4 ist eine korrekte Implementierung von UTF-8 in MySQL/MariaDB, die alle Unicode-Zeichen unterstützt, einschließlich Emojis. Der ältere utf8-Zeichensatz in MySQL/MariaDB unterstützt nur bis zu drei Bytes pro Zeichen und ist keine echte UTF-8-Implementierung, deshalb wird utf8mb4 empfohlen.

    Dieser Befehl erstellt eine neue Datenbank mit dem Namen zabbix unter Verwendung des UTF-8-Zeichensatzes, der für Zabbix erforderlich ist.

    Erstellen Sie einen dedizierten Benutzer für Zabbix und gewähren Sie die notwendigen Berechtigungen: Als Nächstes müssen Sie einen Benutzer erstellen, den Zabbix zum Zugriff auf die Datenbank verwenden wird. Ersetzen Sie <password> durch ein starkes Passwort Ihrer Wahl.

    Erstellen von Benutzern und Gewähren der Berechtigungen

    MariaDB [(none)]> CREATE USER 'zabbix-web'@'<zabbix frontend ip>' IDENTIFIED BY '<password>';
MariaDB [(none)]> CREATE USER 'zabbix-srv'@'<zabbix server ip>' IDENTIFIED BY '<password>';
MariaDB [(none)]> GRANT ALL PRIVILEGES ON zabbix.* TO 'zabbix-srv'@'<zabbix server ip>';
MariaDB [(none)]> GRANT SELECT, UPDATE, DELETE, INSERT ON zabbix.* TO 'zabbix-web'@'<zabbix server ip>';
MariaDB [(none)]> FLUSH PRIVILEGES;
    • Ersetzen Sie <zabbix server ip> durch die tatsächliche IP-Adresse Ihres Servers, auf dem der Zabbix-Server installiert wird.
    • Ersetzen Sie <zabbix frontend ip> durch die tatsächliche IP-Adresse Ihres Servers, auf dem das Zabbix-Frontend installiert wird.

    Wenn beide Komponenten auf demselben Server installiert sind, verwenden Sie dieselbe IP-Adresse.

    Tip

    Wenn Ihr Zabbix-Server, Frontend und Datenbank auf demselben Rechner installiert sind, können Sie <zabbix server ip> und <zabbix frontend ip> durch localhost oder 127.0.0.1 ersetzen.

    Dies erstellt neue Benutzer zabbix-web und zabbix-srv, gewährt ihnen Zugriff auf die Zabbix-Datenbank und stellt sicher, dass die Berechtigungen sofort wirksam werden.

    Bis zu diesem Punkt ist Ihre Zabbix-Datenbank bereit, aber bevor sie tatsächlich von Zabbix verwendet werden kann, müssen Sie die Datenbank mit den notwendigen Tabellen und Initialdaten füllen. Dies wird im nächsten Abschnitt behandelt, wenn wir den Zabbix-Server installieren.

    Wenn Sie beabsichtigen, den Zabbix-Server auf einem anderen Rechner als dem zu installieren, der das Datenbanksystem hostet, müssen Sie die Hostfeuerwaldrules so einstellen, dass eingehende Verbindungen zum Datenbankserver erlaubt sind. Standardmäßig hört MariaDB auf Port 3306.

    Fügen Sie Feuerwaldrules hinzu

    Red Hat / SUSE 

    firewall-cmd --add-service=mysql --permanent
firewall-cmd --reload

    Ubuntu 

    sudo ufw allow 3306/tcp

    Füllen der Zabbix-Datenbank

    Während der Installation des Datenbanksystems zuvor haben wir die notwendigen Benutzer und Datenbank für Zabbix erstellt, allerdings erwartet Zabbix bestimmte Tabellen, Schemata, Bilder und andere Elemente in der Datenbank. Um die Datenbank korrekt einzurichten, müssen Sie sie mit dem erforderlichen Schema füllen.

    Zuerst müssen wir das Zabbix-SQL-Script installieren, das die notwendigen Import-Scripts für die Datenbank enthält.

    Installiere SQL-Scripts

    Red Hat 

    dnf install zabbix-sql-scripts

    SUSE 

    zypper install zabbix-sql-scripts

    Ubuntu 

    sudo apt install zabbix-sql-scripts

    Warning

    Wenn Sie eine aktuelle Version von MySQL oder MariaDB als Datenbankbackend für Zabbix verwenden, können Sie Probleme mit der Erstellung von Triggern während des Schemaimports erleben. Dies ist besonders relevant, wenn das Binärprotokollierung auf Ihrem Datenbanksystem aktiviert ist (Binärprotokollierung wird oft standardmäßig aktiviert). Um dies zu beheben, müssen Sie die log_bin_trust_function_creators Option auf 1 in der MySQL/MariaDB-Konfigurationsdatei oder temporär beim Laufzeitbetrieb setzen. Dies ermöglicht es nicht-root-Benutzern, gespeicherte Funktionen und Triggern zu erstellen, ohne die SUPER Berechtigungen zu benötigen, die eingeschränkt sind, wenn Binärprotokollierung aktiviert ist.

    Normalerweise werden wir diese Einstellung nach dem ersten Import des Zabbix-Schemas nicht mehr benötigen, so dass wir sie danach wieder deaktivieren.

    Aktivieren Sie temporär zusätzliche Berechtigungen für nicht root-Benutzer

    mariadb -uroot -p -e "SET GLOBAL log_bin_trust_function_creators = 1;"

    Nun laden wir die Daten von zabbix (Datenbankstruktur, Bilder, Benutzer usw.) in unsere DB hoch. Hierfür verwenden wir den Benutzer zabbix-srv und laden alles in unsere DB zabbix.

    Füllen Sie die Datenbank

    sudo zcat /usr/share/zabbix/sql-scripts/mysql/server.sql.gz | mariadb --default-character-set=utf8mb4 -uroot -p zabbix

    Warning

    Abhängig von der Geschwindigkeit Ihrer Hardware oder des virtuellen Computers kann der Prozess einige Sekunden bis zu mehreren Minuten dauern, ohne visuelle Rückmeldung nach Eingabe des root-Passworts.

    Bitte haben Sie Geduld und vermeiden Sie es, die Operation abzubrechen; warten Sie einfach darauf, dass das Linux-Prompt wieder erscheint.

    Note

    Zabbix scheint es zu mögen, die Positionen der Skripte zur Füllung der DB in jeder Version oder sogar innerhalb von Versionen zu ändern. Wenn Sie einen Fehler erhalten, schauen Sie sich die Zabbix-Dokumentation an; es besteht eine gute Chance, dass einige Positionen geändert wurden.

    Nachdem das Importieren des Zabbix-Schemas abgeschlossen ist, sollten Sie den log_bin_trust_function_creators globalen Parameter nicht mehr benötigen. Es ist eine gute Praxis, ihn aus Sicherheitsgründen zu entfernen.

    Um den globalen Parameter wieder auf 0 zurückzusetzen, verwenden Sie den folgenden Befehl im MySQL/MariaDB-Shell:

    Deaktivieren Sie die Funktion log_bin_trust erneut

    mariadb -uroot -p -e "SET GLOBAL log_bin_trust_function_creators = 0;"

    Dieser Befehl deaktiviert die Einstellung und sorgt dafür, dass sich das Sicherheitsniveau der Server robust hält.

    Mit dieser Installation von MariaDB ist unsere Arbeit abgeschlossen. Sie können jetzt mit Vorbereitung des Zabbix-Servers fortfahren.

    Schlussfolgerung

    Mit erfolgreicher Installation und Konfiguration von MariaDB als Datenbank- Backend für Zabbix haben Sie eine robuste Grundlage für Ihre Überwachungs-Lösung. Wir haben die Installation von MariaDB aus bereitgestellten Paketen der Anbieter sowie offiziellen Repositories abgedeckt, die Sicherheit der Datenbank, die Erstellung der notwendigen Zabbix-Datenbank und Benutzer sowie das Füllen der Datenbank mit den erforderlichen Schema und Initialdaten.

    Ihr Zabbix-Umfeld ist nun bereit für die nächsten Stufen der Einrichtung und Konfiguration.
