# Теги

Используйте теги, чтобы быстро просматривать материалы по уровню знаний.

- **beginner** — Не требует предварительных знаний Zabbix или предполагает лишь их минимальный уровень. Охватывает основные понятия, установку и простые сценарии использования.
- **advanced** — Предполагает, что читатель знаком с основными функциями и конфигурациями Zabbix. Охватывает более сложные конфигурации, интеграции и темы средней сложности.
- **expert** — Охватывает темы экспертного уровня: масштабирование, высокую доступность (HA), глубокую оптимизацию производительности, пользовательские расширения, нетипичные случаи, сложные архитектуры и усиление безопасности.
