# Tags

Verwenden Sie Tags, um Inhalte schnell nach Kenntnisniveau zu durchsuchen.

- **beginner** — Setzt keine oder nur minimale Vorkenntnisse in Zabbix voraus. Behandelt grundlegende Konzepte, die Installation und einfache Anwendungsfälle.
- **advanced** — Setzt voraus, dass der Leser mit den wichtigsten Funktionen und Konfigurationen von Zabbix vertraut ist. Behandelt anspruchsvollere Konfigurationen, Integrationen und Themen mittlerer Komplexität.
- **expert** — Behandelt anspruchsvolle Themen wie Skalierung, Hochverfügbarkeit (HA), tiefgehende Leistungsoptimierung, benutzerdefinierte Erweiterungen, Sonderfälle, komplexe Architekturen und Sicherheitshärtung.
